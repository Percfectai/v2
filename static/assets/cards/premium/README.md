# Premium card faces (Nick drop-in)

**Product rule:** You make the hero image. The site stamps chrome fast  
(name top-left · short serial top-right · 4 stat bars bottom-left · crowned-P bottom-right).

## How to drop art

1. Save a **vertical** portrait (roughly 2.5∶3.5, sharp, full body or strong 3/4).
2. Name it after the catalog `id`:

   | File | Catalog id |
   |------|------------|
   | `elsa.png` | `elsa` |
   | `princess_jasmine.jpg` | `princess_jasmine` |
   | `cidy.webp` | `cidy` |

3. Put the file **here** (`static/assets/cards/premium/`).
4. Deploy / push. Shop + listings pick it up automatically — no code change needed.

Supported: `.png` `.jpg` `.jpeg` `.webp`

## What we do NOT do for official shop faces

- Mass spam gens that look like cheap packs  
- Random AI chrome baked into the face (stats/logo are code overlays)
