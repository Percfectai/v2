# Percfect TCG layout lock (from Nick’s GoT hero-card refs)

**Refs:** `static/assets/cards/refs/got_ref_{1,2,3}.*`

## Anatomy (print-ready)

```
┌── outer ornate gold / parchment border ──────────────────┐
│  SERIES BANNER (center)     · small # or crest corners     │
│  ┌── portrait window (inset gold frame) ───────────────┐  │
│  │   character keyed on scene (no white wall)            │  │
│  └───────────────────────────────────────────────────────┘  │
│  ╔════════════════════════════════════════════════════╗   │
│  ║  CHARACTER NAME (large, printed plate)             ║   │
│  ╚════════════════════════════════════════════════════╝   │
│  [ATK nn] [DEF nn] [BTY/SPD] [SED/SWG]   · 4 chips      │
│  optional special line · crowned-P logo stamp (corner)    │
└───────────────────────────────────────────────────────────┘
```

## Rules

- Everything is **ink on the card** — no floating CSS stickers
- **No** word “Rare” on face (holo foil only)
- **No** “Lv 1” on face
- **No** 360 as card art
- Name lives on a **solid name plate** under the portrait
- Stats are **small labeled chips** in one row (like STR/DEF on refs)
- Series line = franchise / theme (e.g. PRINCESS SERIES · PERCFECT HEROES)
