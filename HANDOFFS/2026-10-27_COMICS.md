# Perfect Comics — handoff

27 October 2026. This is a new handoff. It does not edit the 25 September handoff or the older PDF.

## Price

One comic is $20. That unlocks the whole book: cover and all nine pages. The 5th finished comic is free, then the count starts over.

There is no $320 balance and no ticket count on the page. The corner says "$20 a comic".

## How the page works

The studio opens on the Cover tab. There is no whole-book generate. Each page is drawn only after the page before it is approved, and that approved picture is the reference for the next page.

A book is 10 pages: cover, then beginning, middle, and ending, three pages each. Writing is free. The first picture on each page is a free watermarked draft. The watermark is the overlay on the page. After the $20 unlock, each page has 2 edits. Three pictures per page, then it stops.

Every picture is `grok-imagine-image-2.0`, 1K, medium. At most 3 reference images.

Publish opens the reader. Selling a comic for a member, with the site keeping 10%, is not built.
